# Prompt inicial (cópialo, rellénalo y pégaselo a Claude)

```
Quiero crear una app. Usa la skill brainstorming y hazme preguntas de una en una
antes de escribir código.

Idea en una frase: [ej. "una app para registrar mis entrenamientos y ver mi progreso"]
Para quién es: [ej. "personas que entrenan en casa, 20–40 años"]
Problema que resuelve: [ej. "olvidan qué peso usaron la última vez"]
Plataforma: [web / móvil (iPhone y Android) / ambas — si no sé, recomiéndame]
3 funciones imprescindibles de la primera versión:
  1. [...]
  2. [...]
  3. [...]
Estilo visual que me gusta: [ej. "minimalista y oscuro, como Linear" / "colorido y divertido"]
Apps de referencia que me gustan: [...]
¿Necesita cuentas de usuario / login?: [sí / no / no sé]
¿Necesita cobrar dinero?: [sí / no / más adelante]

Cuando terminemos el brainstorming: genera el sistema de diseño con ui-ux-pro-max,
escribe el plan con writing-plans y construye la primera versión (MVP) paso a paso.
```

## Consejos
- Empieza con lo mínimo (MVP): 3 funciones, no 20.
- Si no te gusta cómo se ve algo: "usa impeccable para criticar y pulir esta pantalla".
- Si algo falla: "usa systematic-debugging".
